# Roadmap

## M1 — Deterministic Core

Structured TypeScript policy API, path rules, dependency guards, diff budgets, validation, deterministic decisions, package-quality build/test/CI and trust-boundary documentation.

## Planned after M1

- configuration loader and CLI
- Claude Code, Codex, Cursor, Gemini CLI and OpenCode adapters
- natural-language rule compiler as an optional authoring aid; deterministic rules remain enforcement truth
- MCP integration and broader developer workflow tooling
- benchmark/evaluation suite measuring rule correctness, adapter observation coverage and overhead; no benchmark numbers are claimed yet

Cloud services, dashboards, authentication, billing and telemetry are not part of the current implementation.
